# ☕ Exercícios Práticos em Java

Repositório dedicado ao armazenamento, organização e evolução contínua de exercícios práticos desenvolvidos durante o estudo da linguagem **Java** e do seu ecossistema.

---

## 📌 Projetos no Repositório

Aqui estão listados os exercícios desenvolvidos até ao momento, organizados por módulo e conceito explorado:

| Exercício | Conceitos Aplicados | Descrição |
| :--- | :--- | :--- |
| **`ExercicioContaBancaria`** | Encapsulamento, Construtores, Sobrecarga | Simulação de operações bancárias (saque/depósito) com regras de taxas e saldos. |
| **`ExercicioContribuintes`** | Classes Abstratas, Polimorfismo, Coleções | Cálculo de impostos para pessoas físicas e jurídicas utilizando métodos abstratos. |
| **`ExercicioProduto`** | Herança, Polimorfismo, Sobrescrita de Métodos | Gestão e etiquetagem de preços para produtos comuns, importados e usados. |
| **`ExercicioReserva`** | Exceções Personalizadas, Regras de Negócio | Sistema de reservas de hotel com validação de datas via `DomainException`. |
